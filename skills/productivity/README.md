# Productivity

General workflow tools, not code-specific.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[ppt-design](./ppt-design/SKILL.md)**: Design and produce a deck. Methodology (logic, visual and structure frameworks, type scale, whitespace, colour, wall-of-text handling, page templates, narrative pacing) plus an execution engine that generates a deck from a topic, article, script or outline, or beautifies an existing `.pptx` against a reference image without changing its text. Ships 14 style presets, an icon library and a five-dimension self-review chain.
- **[ppt-master](./ppt-master/SKILL.md)**: A tool-neutral deck workflow written in Chinese: clarify the request, structure the narrative, set the design system (palette, fonts, type scale, spacing, one recurring motif), rotate through a layout library, follow the data-visualisation rules, then build or edit the file and QA every rendered page. Covers both pptxgenjs and python-pptx, structured decks driven by a theme and layouts, and the implementation pitfalls of each.
