# Built-in Icons

From Lucide (ISC license), pre-rasterized as white PNGs, tinted at build time from the palette, and usable offline.

Just fill in a name in `icons`, `takeaway_icon`, or `lead_icon` in plan.json, or in an icon element of the free layout.
`plan_deck.py` matches automatically using the keywords in the table below, and falls back to the layout's default icon when nothing matches.
